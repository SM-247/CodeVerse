## 🧠 AI Agent Capabilities

The BloodLinkAgent analyzes:

1. **Current Inventory** - Available blood units per type
2. **Upcoming Surgeries** - Scheduled procedures with requirements
3. **Demand Forecasting** - Total blood needed from surgeries
4. **Shortage Identification** - Which blood types are short
5. **Hospital Recommendations** - Which hospitals can help
6. **Urgency Calculation** - How critical is the shortage

**Output Example:**
```json
{
  "bloodGroup": "O+",
  "available": 10,
  "required": 15,
  "shortage": 5,
  "urgency": "high",
  "recommendedHospitals": [
    {"hospital": "metro", "available": 14, "score": 0.93}
  ]
}
```
